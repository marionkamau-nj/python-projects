# Student Records Manager Using File Handling

## 1. Project Description
The Student Records Manager is a beginner Python project that collects, saves, and displays student information using file handling.

The program stores student details in a text file called `students.txt`.

## 2. Features
- Collects student personal and academic information.
- Saves student records to a text file.
- Appends additional student records.
- Reads and displays saved student information.
- Handles invalid admission year input using `try` and `except`.

## 3. Student Information Collected
The program collects:
- Student Name
- Registration Number
- Course
- Year of Study
- Department
- Email Address
- Phone Number
- Academic Year
- Semester
- County
- Admission Year
- Student Status

## 4. Python Concepts Practised
- Variables and user input
- Data type conversion using `int()`
- Conditional error handling with `try` and `except`
- Loops using `while`
- File handling using `w`, `a`, and `r` modes
- Writing and reading text files
- String formatting using f-strings

## 5. Technologies Used
- Python
- Visual Studio Code
- Git and GitHub

## 6. How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal in the project folder.
5. Run the command:

   `python student_records.py`

6. Follow the prompts to enter student information.
